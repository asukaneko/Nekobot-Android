# 单会话角色记忆第二版

## 问题与目标

旧聊天在形成记忆之前就退出近期窗口、整批失败回滚、逐字引用难以核验和旧版物理删除，会削弱单会话角色记忆的连续性与可追溯性。本变更改为发送前总结、编号证据、JSONL逐条入库、软删除和明确的用户选择。

## 范围

采用数据库63→64增量迁移，接入五语离线时间词库及界面、待确认记忆、锁定处理队列、消息变更的关联记忆选择、出处快照与作废版本恢复。近期原文默认约8000，达到预算时按最早完整轮次滚动总结约2000，成功持久化才移出近期输入；恢复预算即停止，原文仍可回看。完整长轮不裁剪，失败有界重试并说明原因，未成功不继续普通回复。此规则替代早期强制连续处理首个长轮的安排。普通聊天和非融合记忆路径保持原规则。

行为、实现入口与自动化回归对应见`docs/memory-v2.md`及本变更的规格文件。本文仅记录可公开的产品契约，不包含工作站配置、运行日志或真实用户数据。
