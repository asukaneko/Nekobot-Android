# 作者布局与伴侣默认提示词（2026-10-24）

用户决定让“更多/设置”采用作者的分组长列表，暂时不用五分类更多首页；随后明确授权优化长期AI伴侣的默认提示词，并一起更新PR31。此决定替代上一轮保留自定义导航的要求，不取消记忆、数据保护或其他业务功能。

## 页面范围

更多页恢复外观、AI能力、功能、系统、设置等上游分组。设置恢复运行模式、服务器配置、高级功能、备份、Agent设置、日志诊断、账号、语言和关于的同页组织。所有既有业务入口保持；余额、Kimi功能保留。

保留防重复导航、返回位置恢复、可访问整行开关与错误提示。旧分类组件及路由暂留兼容，但不再从首页进入，不删除历史数据。没有把上游整仓覆盖到贡献分支；逐项核对两个页面的差异。同期上游新增Kimi Code授权支持（230842fe）正常合入，不在此实现额外OAuth行为。

## 默认提示词盘点与选择

| 位置 | 用途与发现 | 本轮处理 |
| --- | --- | --- |
| CharacterThinkingStyle.kt | 普通角色、群聊与单会话共用的默认思考文案；旧文案固定三步、要求想起小事，并给出未经本轮证实的生活例子，反复要求把思考写成中文 | 改为内部判断事实、情绪和回应需要；不要求公开逐步推理，不添加虚构经历；功能开关、原生流解析、工具格式不变 |
| CompanionPromptLanguage.kt / CompanionPromptSettings.kt | 单会话默认说话方式与编辑回退；旧文案只有简短口语要求，对关心、不同意见、收尾和能力边界交代不足；styleReminder重复文案 | 补自然接话、适度关心、少机械反问、不一味附和、按已确认关系调整亲近程度；styleReminder复用同一默认说话块 |
| AIPipeline.kt / CharacterPromptBuilder.kt / CharacterThinkingRule.kt | 说话块在角色固定层，思考块仅在请求尾部；气泡分隔独立；自定义说话替换默认 | 不改拼接层级与用户原话；测试默认只注入一次、尾部时钟和开关仍有效 |
| CompanionPromptStore.kt | 会话初始化、保存、重开与导入；非空保存内容优先 | 不改存储逻辑、不迁移用户数据；已保存的旧默认全文视作自定义继续保留。仅空值“跟随默认”采用新文案 |
| FusedCompanionPolicy.kt / FusedMemoryOperation.kt | 记忆操作JSONL、S/M/N编号、证据与done结束协议 | 保持原协议；不可用自然聊天文案替换；沿用解析、部分保存和重试回归 |
| CompanionRelationshipPrompt.kt / AgentSummaryPrompt.kt | 历史关系状态、未知时间与不可信历史资料边界 | 已明确历史不等于当前情绪、摘要不授予操作权限；保留 |
| LocalAgentPrompt.kt | 通用任务助手、工具权限与已完成动作报告 | 现有权限和不泄露推理要求有效；不把通用Agent改成陪聊，不扩大工具授权 |

默认聊天直接回应具体内容，按情况调整长短；不每轮舞台动作、替对方台词或重复人设。不声称现实身体、线下行动或持续后台活动；不使用排他、监控或内疚挽留。亲近不等于强制恋人关系；用户自定义关系、人设与说话全文继续优先。

没有新增主动消息调度、真实模型调用或长期效果承诺。约8000/~2000滚动、成功才推进、失败同批重试、不确定事件日期留空、来源与记忆保存全部保持。

## 依据与验证边界

参考[Kindroid人格设置说明](https://kindroid.ai/v2/docs/customizing-personality/)对人格、回复指令、记忆和示例的分层，以及[记忆说明](https://kindroid.ai/v2/docs/memory/)对上下文与检索记忆的区分。这里选择适合本项目已有架构的清晰职责和连续性要求，不复制其产品机制。

[OpenAI与MIT情感使用研究](https://openai.com/index/affective-use-study/)指出效果与使用方式及个人因素有关。上述文案是设计选择，不是自然度、长期关系效果或疗效已经得到证明；不能以聊天时长作为唯一成功标准。

程序验证覆盖当前布局入口、状态恢复/返回、防重复、默认/自定义兼容、历史自定义全文保留、请求拼接及原结构化协议。合成的分享、抱怨、离开、更正、不同意见和续接旧话题只验证请求构造与原话保留，不冒充真实模型行为测试。实际结果待本轮验证完成后写入tasks.md。
