主模型挂了也不怕

7 类用途独立故障转移队列：chat / vision / video / tts / stt / embedding / image_generation。P0 主模型故障时自动切换 P1 / P2 备用，日 / 周 token 限额超限自动跳过，连续失败进入冷却期。状态码感知的退避策略，429 / 500 都有不同的处理。

FAQ

好奇宝宝问与答

Nekobot 是免费的吗？
完全免费，且基于 GPL v3 开源。没有广告、没有内购，AI 调用的费用取决于你自己配置的 API。
没有服务器可以用吗？
可以！切换到「本地模式」，填入任意 OpenAI 兼容 API 的地址和密钥即可。所有数据都保存在手机本地，不需要任何后端。
我的对话数据安全吗？
本地模式下数据只存在你的设备里（Room 数据库），支持 WebDAV 备份到你自己信任的位置。服务器模式下数据流向取决于你连接的后端，建议只连接自己部署的服务。
支持哪些 AI 模型？
本地模式支持任何 OpenAI 兼容接口（OpenAI、DeepSeek、Gemini 兼容端点、本地部署的开源模型等）。应用内可以管理多个模型配置、克隆与故障转移队列。
可以导入 SillyTavern 的角色卡吗？
完全支持！本地模式导入角色卡兼容 nekobot 协议（.json / .zip）和 SillyTavern 酒馆格式：包括 v2 flat snake_case JSON、v3 data 包裹层 JSON，以及 PNG 嵌入式角色卡（自动从 tEXt chunk 的 chara / ccv3 提取 base64 JSON，PNG 本身还会作为角色立绘）。
Agent 模式是什么？AI 真的会自己干活吗？
是的。切换到 Agent 模式后，AI 可以操作会话内的原生浏览器、读取动态 DOM 与 URL、在 Alpine Linux 沙箱执行命令、处理工作区文件，并组合 Skills、数据库和 MCP 工具。每一步都会显示在进度卡片中；高风险命令需要确认，重复无进展的工具调用也会自动停止。
角色会记得我们之前聊过的事吗？
会！Nekobot 有完整的记忆系统：每轮对话后自动抽取关键事件写入角色记忆，每轮自动保存状态快照（情绪、精力、关系六维）。还有"静默心跳生活模拟"——你离开 60 分钟后，下次发消息时系统会自动补生成一段角色独处时的生活片段写入记忆库，让 AI 后续对话能引用这段经历。深夜时段只生成睡眠 / 梦境内容。
主 AI 模型挂了会怎么样？
故障转移队列会自动切换备用模型！7 类用途（chat / vision / video / tts / stt / embedding / image_generation）各有独立的优先级队列（P0 主选、P1、P2…）。P0 故障时自动尝试 P1，连续失败会进入冷却期，日 / 周 token 限额超限也会自动跳过。状态码感知的退避策略让 429 / 500 都有不同处理。
支持哪些语音输入方式？
支持 OpenAI 兼容协议和小米 MiMo 原生协议两种 STT。如果模型 provider 配为 xiaomi 或 mimo，会自动走 MiMo API（端点 /v1/chat/completions，认证头 api-key）。录音非 wav 时（m4a / aac / webm / ogg / flac）会用原生 MediaCodec 转码为 16kHz 单声道 WAV，APK 体积零增加。STT 模型也走故障转移队列。
