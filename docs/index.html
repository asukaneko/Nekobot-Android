FAQ

好奇宝宝问与答

Nekobot 是免费的吗？
完全免费，且基于 GPL v3 开源。没有广告、没有内购，AI 调用的费用取决于你自己配置的 API。
没有服务器可以用吗？
可以！切换到「本地模式」，填入任意 OpenAI 兼容 API 的地址和密钥即可。所有数据都保存在手机本地，不需要任何后端。
我的对话数据安全吗？
本地模式下数据只存在你的设备里（Room 数据库），支持 WebDAV 备份到你自己信任的位置。服务器模式下数据流向取决于你连接的后端，建议只连接自己部署的服务。
支持哪些 AI 模型？
本地模式支持任何 OpenAI 兼容接口（OpenAI、DeepSeek、Gemini 兼容端点、本地部署的开源模型等）。应用内可以管理多个模型配置、克隆与故障转移队列。
可以导入 SillyTavern 的角色卡吗？
角色卡支持导入功能，兼容常见的角色卡字段（描述、人格、首条消息、场景、对话示例等），导入后可继续编辑完善。
